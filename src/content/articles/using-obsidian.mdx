### MusicAbc

MusicAbc est un langage de notation musicale basé sur du texte. Il est utilisé pour créer des partitions musicales à partir de fichiers texte simples. 
MusicAbc est particulièrement populaire pour la notation de musique traditionnelle et folklorique, mais il peut également être utilisé pour prendre des notes sur Obsidian.

D'abords, desactiver le mode restreint dans `Paramètres > Modules complémentaires` puis rechercher *ABC Music Notation* dans les modules de la communauté et l'activer.

Une fois que c'est fait, vous pouvez utiliser un bloc de code avec le language `abc` pour écrire de la musique.

````markdown
```abc
X:1
M:2/4
L:1/8
K:Gm clef=bass
L[G, C,G,,C,,]zz2|L[G, C,G,,C,,]zz2|L[_A, C,G,,C,,]zz2|L[_A, C,G,,C,,]zz2|
```
````
